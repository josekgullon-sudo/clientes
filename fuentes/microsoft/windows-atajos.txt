Métodos abreviados de teclado de Windows
Se aplica a Windows 11 Windows 10
Windows 11
Windows 10
Los métodos abreviados de teclado son combinaciones de teclas que proporcionan un modo alternativo para hacer algo que se suele realizar con un ratón.
Si estás intentando tomar una captura de pantalla o captura de pantalla, consulta Usar la herramienta Recortes para capturar capturas de pantalla .
Nota
El comportamiento de algunos métodos abreviados de teclado puede variar en diferentes aplicaciones. Por ejemplo, es posible que Ctrl + Mayús V + para pegar como texto sin formato no funcione en todas las aplicaciones.
Algunas aplicaciones pueden cambiar el comportamiento de algunos métodos abreviados de teclado. En este artículo se enumeran los métodos abreviados de teclado predeterminados de Windows.
